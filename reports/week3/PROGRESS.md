## Ablation interpretation

- Removing text reduced both ranking metrics compared with the full model.
- Removing age improved Recall@20 but decreased NDCG@10 and AUC. Do **not** claim that age improves every metric.
- Causal interpretations and statistical significance require repeat seeds and a careful check of feature fitting. **AUC caution:** the current `ranker_auc` function does not take the `no_age` flag, so the No Age AUC reported by `src.train` is not a clean age-free evaluation; treat it as exploratory rather than a definitive ablation comparison.

## Sample integrity checks (initial)

The local checks reported **0 duplicate Train/Test prediction keys** and **0 future-history events** on the test set. The new script also checks Train/Validation and Validation/Test duplicates, and the three splits' history dates.

**Important limitation:** This is not a comprehensive data leakage audit. In particular, the current `src/train.py` builds TF-IDF/SVD text vectors from the full items table. The project should explicitly decide whether the evaluation is *transductive* (all item metadata considered available) or needs to fit text transformations on training-only information. Validation/model-selection isolation also needs review before answering Q3 "Yes".

## Reproduction

From the repository root with Python 3.12:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-week3.txt
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m scripts.week3_evaluate --protocol both --seed 0
```

This generates `reports/week3/baseline_metrics.csv` and `reports/week3/data_checks.json`. It does **not** re-train or overwrite model checkpoints.
